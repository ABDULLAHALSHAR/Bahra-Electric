# منصة بحرة إلكتريك للتدريب والتطوير

منصة تدريب وتطوير للموظفين بالذكاء الاصطناعي، مبنية وفق المعمارية:
**GitHub Pages → Google Apps Script (`Code.gs`) → Google Sheets**.

## الملفات
| الملف | الوصف |
|---|---|
| `index.html` | الواجهة الكاملة (تسجيل الدخول + لوحة التحكم) — HTML/CSS/JavaScript، تعمل مباشرة بالبيانات المضمّنة. |
| `bahra_platform_database.xlsx` | قاعدة البيانات (10 صفحات) — ارفعها إلى Google Sheets لتصبح المصدر الحيّ. |
| `Code.gs` | خادم Apps Script: تسجيل الدخول، الصلاحيات، قراءة البيانات، ومساعد «اسألني» عبر Groq. |

## التشغيل السريع (بدون خادم)
افتح `index.html` مباشرة — يعمل بالكامل ببيانات 50 موظفاً المضمّنة.
حسابات تجريبية جاهزة على شاشة الدخول (مدير / مدرب / موظف).

## الربط بالخادم (نسخة حيّة)
1. ارفع `bahra_platform_database.xlsx` إلى Google Drive وافتحه كـ Google Sheet (حافظ على أسماء الصفحات كما هي).
2. من محرر Apps Script الصق `Code.gs`، واضبط `SHEET_ID` و `GROQ_API_KEY`.
3. انشر كـ **Web app** (Execute as: Me — Access: Anyone) وانسخ الرابط.
4. في أعلى `<script>` داخل `index.html` اضبط:
   ```js
   CONFIG.APPS_SCRIPT_URL = "رابط_النشر";
   CONFIG.USE_BACKEND = true;
   ```
5. ارفع `index.html` إلى مستودع GitHub وفعّل **GitHub Pages**.

## الأدوار والصلاحيات
- **Admin**: كل الوحدات (بما فيها الموظفون، المدربون، الإعدادات).
- **Trainer**: الدورات، الجلسات، الطلبات، التقييم، الاحتياج، التقارير.
- **Employee**: يرى دوراته وطلباته وشهاداته فقط.

اللغتان (عربي/إنجليزي) والوضع الداكن قابلان للتبديل من الشريط العلوي.
