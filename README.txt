BAHRA ELECTRIC TRAINING PLATFORM - APPS SCRIPT VERSION

هذه النسخة لا تستخدم GitHub Pages ولا fetch ولا API_URL.
كل شيء يعمل داخل Google Apps Script باستخدام google.script.run.

الملفات المطلوبة داخل Apps Script:
1) Code.gs
2) Index.html
3) CSS.html
4) JavaScript.html

الخطوات:
1. افتح مشروع Google Apps Script الحالي.
2. احذف الكود القديم من Code.gs والصق Code.gs الجديد.
3. أضف ملف HTML باسم Index والصق محتوى Index.html.
4. أضف ملف HTML باسم CSS والصق محتوى CSS.html.
5. أضف ملف HTML باسم JavaScript والصق محتوى JavaScript.html.
6. احفظ المشروع.
7. شغّل setupSystem مرة واحدة ووافق على الصلاحيات.
8. Deploy > Manage deployments > Edit > New version > Deploy.
9. Execute as: Me
10. Who has access: Anyone
11. افتح رابط /exec وسيكون هو رابط المنصة نفسها.
